# wa-blast Project Info

## Purpose
Standalone WhatsApp multi-tenant SaaS for blast campaigns + inbox. Independent product (not dependent on Chatwoot). Uses Meta Cloud API directly.

## Tech Stack
- **Runtime**: Bun
- **Framework**: Next.js 16 (App Router)
- **Database**: Drizzle ORM + better-sqlite3 (SQLite)
- **Auth**: Better Auth
- **UI**: shadcn/ui, Tailwind v4
- **Testing**: Vitest, Playwright
- **Linting**: ESLint

## Key Files & Structure
- `/src/lib/db/schema/` - Drizzle schema definitions (auth.ts, domain.ts)
- `/drizzle/migrations/` - SQL migrations auto-generated by drizzle-kit
- `/src/lib/db/client.ts` - Database client initialization
- `/src/lib/db/test-db.ts` - Test database setup
- Task checklist at `/src/lib/db/schema/domain.ts` (3 tables added in Task 1)

## Important Commands
- `bun run db:generate` - Generate migrations from schema
- `bun run db:migrate` - Run pending migrations
- `bun test` - Run all tests (has pre-existing issues with env vars)
- `bunx tsc --noEmit` - Type check (must pass before commit)
- `bun run lint` - ESLint check

## Database Schema Location
All domain tables live in `/src/lib/db/schema/domain.ts` and are re-exported via `/src/lib/db/schema/index.ts`
